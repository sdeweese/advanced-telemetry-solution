# TorIX Modern Network Telemetry Solution

## Overview

This repository contains the TATS (TorIX Advanced Telemetry System) solution. It includes the documentation, code, configurations, IaC, and other related materials. All aspects of the project have been captured here, with the exception of a Linux daemon, which is in another GitLab repository.

![High-Level Responsibilities Diagram](https://gitlab.torix.ca/tats/documentation/-/raw/main/tats-user-manual/Diagrams/bf-torix-tats-highlevel-services.png?ref_type=heads)

## Documentation

The project is fully documentated in the dedicated [documentation respository](https://gitlab.torix.ca/tats/documentation/-/tree/main/tats-user-manual?ref_type=heads). The repository is used to compile the User Manual as a PDF which can be found [here](https://gitlab.torix.ca/tats/documentation/-/blob/main/tats-user-manual/tats-user-manual.pdf?ref_type=heads).
